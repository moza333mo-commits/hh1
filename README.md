# Audio Route Tester

مشروع أندرويد تجريبي لفحص أجهزة إدخال وإخراج الصوت وقياس وصول إشارة الميكروفون.

## البناء
- افتح المجلد في Android Studio حديث.
- اسمح بمزامنة Gradle.
- اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
- ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

يمكن أيضاً رفع المشروع إلى GitHub وتشغيل GitHub Actions من تبويب Actions لبناء APK.

## حدود الاختبار
هذا التطبيق يعرض أجهزة الصوت التي يعلنها النظام ويختبر التقاط الميكروفون. لا يستطيع تطبيق أندرويد عادي إجبار واتساب أو تطبيق الهاتف على استخدام مدخل صوت محدد؛ القرار النهائي يعتمد على Android والشركة المصنّعة والتطبيق أثناء المكالمة.
